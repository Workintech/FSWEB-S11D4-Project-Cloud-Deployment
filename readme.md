# Gün Projesi: Project Cloud Deployment

Şirkette kullanılan serverlar artrık çok maaliyet oluşturmaya başladı. Bu yüzden sürekli ertelenen cloud geçişi artık kaçınılmaz oldu.

Eldeki projeleri cloud sistemlere deploy etme işleri ekip içinde paylaşıldı. Senden de 3 projeyi cloud'a deploy etmen isteniyor.

- [ ] https://github.com/Workintech/fsweb-s10g2-redux-filmler-solution, https://github.com/Workintech/fsweb-s10g3-redux-watchlist-solution, https://github.com/Workintech/FSWeb-S9-Sprint-Challenge-solution adreslerindeki 3 projeyi de forkla.
- [ ] render.com, vercel.com gibi sitelerde yayına al.
- [ ] uygulamanın erişilebilir olduğundan emin olduğunda `index.js` dosyasında uygulamaların URLlerini ekle.

## Önemli Notlar

- Proje dizinindeki `user.json` dosyasını bulun ve `user_id` alanını NextGen proje ekranında görünen kendi `user_id` değeriniz ile güncelleyin.
- Geliştirme sırasında testleri izlemek için `npm test` komutunu kullanın.
- Testleri çalıştırıp skoru NextGen'e kaydetmek için `npm run sendresults` komutunu kullanın.
